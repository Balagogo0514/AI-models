# Collaboration Rules

## Confirmation Mode

- Before creating, modifying, moving, or deleting any file, describe the proposed changes and wait for the user's explicit approval.
- Do not treat a request for information, analysis, or an explanation as approval to edit files.
- Reading files, searching the workspace, and running non-modifying diagnostic commands do not require approval.
- After approval, make only the agreed changes. Ask again if the scope materially changes.
